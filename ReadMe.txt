203.7000 Game Development in Game Engines
Unity 6.3 LTS (6000.3.26f1)

Assignment 1
------------
Open the scene Assets/Scenes/Assignment_01.unity and press Play.

Controls: WASD to move.

Rules:
- Collect coins to reach the target score (1000).
- If the enemy touches you, you lose.
- The result is printed to the Console ("you won" / "you lose"), and Play mode stops.

Where things are:
- Scripts: Assets/Scripts/Assignment01/
- Prefabs: Assets/Prefabs/Assignment01/

Settings in the Editor:
- Coin value and color: the variants Orange_Coin, Green_Coin and Blue_Coin
- Spawn range and batch size: the CoinSpawner prefab
- Target score: the Player in the scene

Other files
-----------
SampleScene and PlayerMovement.cs are class work from lecture 1, not part of the assignment.
